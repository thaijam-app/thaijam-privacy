ThaiJam — demo track for App Review

This page exists only for App Review. The audio below is a 72-second recording produced by ThaiJam from its own text-to-speech material; we own all rights to it. Use it to test song import, lyrics, sing-along and background playback without needing any third-party music service.

1. Download the audio

ThaiJam - Everyday Thai Phrases.m4a

On iPhone or iPad: press and hold the link and choose “Download Linked File”. Tapping it just opens the built-in player. The file is saved to Files → Downloads.

2. Import it

In ThaiJam: Songs → + → import audio → Browse → Downloads, and pick the file. Play it, then lock the screen — playback continues.
